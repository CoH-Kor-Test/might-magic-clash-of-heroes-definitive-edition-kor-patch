# Might & Magic: Clash of Heroes - Definitive Edition kor patch

Might & Magic: Clash of Heroes - Definitive Edition용 한국어 패치 패키지입니다.

## 번역 안내

이 번역은 AI 번역을 사용했으며, 아직 전체 내용을 충분히 검수하지 못했습니다. 오역이나 오류를 발견하시면 [Issues](https://github.com/CoH-Kor-Test/might-magic-clash-of-heroes-definitive-edition-kor-patch/issues)에 제보해 주세요. 확인 후 수정할 수 있도록 노력하겠습니다.

## 사용법

1. `M&M_Clash_of_Heroes_DE_kor_v0.1.zip`을 원본 게임 폴더에 풉니다. 같은 폴더에 `data.inf`와 `data.bin`이 있어야 합니다.
2. `패처 실행.bat`을 실행합니다.
3. 패치 완료 후 원본 파일은 `backup/data.inf`와 `backup/data.bin`에 보관됩니다. 패치된 두 파일은 게임 폴더에 생성됩니다.

## 사용 도구

이 패키지는 [Hinoroni/InfBinRepacker](https://github.com/Hinoroni/InfBinRepacker)를 사용하여 아카이브를 언팩하고 패치 파일을 적용한 뒤 다시 리팩합니다.

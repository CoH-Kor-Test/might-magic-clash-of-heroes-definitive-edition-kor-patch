# Might & Magic: Clash of Heroes - Definitive Edition kor patch

Might & Magic: Clash of Heroes - Definitive Edition용 한국어 패치 패키지입니다.

## 다운로드

저장소 화면 오른쪽의 **Releases**에서 최신 버전을 열고, **Assets** 목록의 **Might_and_Magic_Clash_of_Heroes_DE_Korean_Patch_v0.1_Standalone_with_DotNET8.zip**을 다운로드하세요. 이 패키지에는 .NET 8 런타임이 포함되어 있어 별도로 설치하지 않아도 됩니다.

[릴리스 페이지 바로가기](https://github.com/CoH-Kor-Test/might-magic-clash-of-heroes-definitive-edition-kor-patch/releases)

## 번역 안내

이 번역은 AI 번역을 사용했으며, 아직 전체 내용을 충분히 검수하지 못했습니다. 오역이나 오류를 발견하시면 [Issues](https://github.com/CoH-Kor-Test/might-magic-clash-of-heroes-definitive-edition-kor-patch/issues)에 제보해 주세요. 확인 후 수정할 수 있도록 노력하겠습니다.

## 사용법

1. 게임 언어를 일본어로 설정합니다.
2. Releases의 Assets에서 받은 런타임 포함 ZIP을 원본 게임 폴더에 풉니다. 같은 폴더에 data.inf와 data.bin이 있어야 합니다.
3. 패처 실행.bat을 실행합니다.
4. 패치 완료 후 원본 파일은 backup/data.inf와 backup/data.bin에 보관됩니다. 패치된 파일은 게임 폴더에 생성됩니다.

## 사용 도구

이 패키지는 [Hinoroni/InfBinRepacker](https://github.com/Hinoroni/InfBinRepacker)를 사용하여 아카이브를 언팩하고 패치 파일을 적용한 뒤 다시 리팩합니다.
